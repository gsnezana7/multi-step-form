# Пошаговая форма подписки (Multi-step subscription form)

Интерактивный многошаговый веб-интерфейс оформления подписки, разработанный с фокусом на плавный пользовательский опыт (UX) и строгую валидацию данных.

## 🚀 Демонстрация проекта

- **Живой сайт (Netlify):** https://netlify.app

## 🛠️ Стек технологий и архитектура

- **Логика и реактивность:** Vue 3 (Composition API) — обеспечивает мгновенное переключение шагов без перезагрузки страницы и динамический расчет стоимости.
- **Сборка проекта:** Vite — для быстрой оптимизации ресурсов и высокой скорости загрузки.
- **Верстка:** HTML5, CSS3.
- **Методология кода:** БЭМ (Блок-Элемент-Модификатор) — гарантирует модульность стилей, отсутствие конфликтов в CSS и легкую поддержку интерфейса в будущем.

## 💡 Реализованный функционал

1. **Многошаговость (Multi-step):** Логическое разделение процесса на этапы (выбор плана, выбор дополнений, итоговый чек).
2. **Клиентская валидация:** Защита от дурака на этапе ввода персональных данных (проверка email, телефона, обязательных полей).
3. **Динамический переключатель:** Перерасчет цен в зависимости от выбранного периода (месяц / год) с предоставлением скидок.
4. **Итоговый экран:** Финальная калькуляция всех выбранных услуг перед отправкой формы.
5. **Адаптивный дизайн:** Интерфейс корректно подстраивается под любые разрешения экранов, включая мобильные устройства.

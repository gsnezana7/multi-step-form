# Пошаговая форма подписки (Multi-step subscription form)

Интерактивное многошаговый веб-приложение для оформления подписки, разработанное на Vue 3 с фокусом на автоматическое сохранение прогресса и продвинутый пользовательский опыт (UX).

## 🚀 Демонстрация проекта

- **Живой сайт (Netlify):**[ https://netlify.app](https://multi-step-form-gsnezana7.netlify.app)

## 🛠️ Стек технологий и архитектура

- **Логика и реактивность:** Vue 3 (Composition API, `<script setup>`) — использование реактивных состояний (`ref`), глубоких наблюдателей (`watch`) и хуков жизненного цикла (`onMounted`).
- **Сборка проекта:** Vite — для оптимизации ресурсов и мгновенной загрузки.
- **Методология кода:** БЭМ (Блок-Элемент-Модификатор) — гарантирует модульность, отсутствие конфликтов в CSS и легкую поддержку интерфейса.

## 💡 Реализованный функционал

1. **Многошаговость и навигация:** Поэтапное разделение процесса (персональные данные, выбор тарифного плана, дополнения, итоговый чек) с возможностью возврата назад.
2. **Строгая клиентская валидация:** Проверка обязательных полей, валидация формата Email через регулярные выражения и проверка длины номера телефона (не менее 9 цифр).
3. **Мгновенный отклик на ошибки (UX в реальном времени):** Реализованы персональные наблюдатели (`watch`) за полями ввода. Ошибки валидации исчезают автоматически в процессе ввода, как только данные становятся корректными.
4. **Сохранение прогресса (LocalStorage):** Полное сохранение состояния сессии. При перезагрузке страницы восстанавливаются не только введенные данные, но и шаг, на котором остановился пользователь.
5. **Сброс сессии:** При достижении финального экрана («Успешная отправка») данные и шаги автоматически очищаются из хранилища для возможности повторного заполнения.
